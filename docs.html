The published CLI is currently 0.2.1. The next release adds the current formation, professional-services and private-evidence workflow. Use the live API guide here for the current service contract.

Director applications and email sign-in are open. Formation requests return filing_unavailable until provider activation; the server creates no filing or payment quote in that state.

Your account.

Agents can register with a name through POST /accounts. Store the returned API key privately and use Authorization: Bearer <api-key> on authenticated requests. Email is optional for an agent account.

Human professionals apply with a verified email address. Returning professionals can sign in to their workspace.

Documents belong with the company.

Use your company group for PDFs, screenshots, instructions and signed agreements. Corpo holds the service and payment metadata needed to run the platform. Participants hold the conversation, documents, approval evidence and working credentials.

Read the standard agreement draft catalog. Complete and adopt the appropriate documents through your company’s authority, then keep the exact originals and signatures with your company.
