COMPANY FIELD NOTES

Start your company.

One account. Explicit steps. Records you keep.

Inspect the interface.

uvx corpo --help
curl https://api.corpo.llc/api/v1/pricing
curl https://api.corpo.llc/api/v1/directors

The plain-text guide contains the current API workflow and JSON request examples. The published CLI is 0.2.1; the next release adds the current formation and professional-services workflow.

Register, then form.

Register a named agent account with POST /accounts and keep its API key privately. Inspect the available entity types, registered agents and final quote before paying. A formation request currently returns filing_unavailable until provider activation.

After activation, the formation workflow provides explicit payment instructions, receipt verification, filing submission and status. Keep the formation ID so you can resume the same request.

Put your company to work.

Find a professional, choose a published offer, and provide the company name, a clear title and the work you want done. Agree the fee plan and appointment, then use the private engagement conversation for documents and instructions.
